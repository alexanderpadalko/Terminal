# КРИПТА и сохранение положения графика — 15.11.2026

Версия остаётся **0.2.26**. Прямое решение пользователя: исправить сброс вида при переподключении и добавить **BTCUSDT.P / ETHUSDT.P** Binance в раздел **КРИПТА**.

## Поведение

- При обновлении того же symbol/venue/TF FinamWindow восстанавливает текущие сдвиг, дробный масштаб, пустое пространство справа и ручной диапазон цены после `set_analysis`. Состояние берётся **при получении результата**, чтобы сохранить жесты во время загрузки. При добавлении свечей история остаётся привязана к тому же времени. Четыре регрессии до исправления падали, после исправления прошли, включая HTTP после ready/reconnect и MN1 с одной свечой.
- При смене инструмента сохраняется прежний сброс диапазона к собственным ценам; End/F остаются явными командами перехода к последним/автоцене. Логика свечей/потоков/FVG не менялась.
- К существующим 38 добавлены ровно два **Binance USD-M USDT PERPETUAL**; всего **40**. КРИПТА — отдельная группа после акций РФ. Поиск, фильтры H1/H4/D/W/M и скринер общие. Crypto-only без Finam-токена проверяет два криптоактива, с Finam — все 40.
- Binance использует публичные read-only данные без ключа. REST подтверждает `PERPETUAL`, `TRADING`, USDT quote/margin; допустимы только exchangeInfo, klines и ticker/price V2. Спот, mark/index, приватные данные и торговые методы не используются. Цена — LAST, исходные свечи — нативные 1m/5m/1h/4h/1d/1w/1M. Закрытие свечи берётся от Binance, включая календарные месяцы; диапазоны start-inclusive/end-exclusive, пагинация ограничена и проверяет продвижение.
- Собственный SQLite **binance_candles_v1.sqlite3**, отдельная отменяемая очередь. Существующий Finam SQLite не смешивается с Binance. Binance не становится резервным источником для прежних инструментов. Экспирации фьючерсов остаются только Finam; MOEX только рейтинг акций.
- WebSocket — актуальный `/market/stream`, публичный aggTrade для LAST и семь kline. Переподключение вызывает восстановление по HTTP, закрытие отменяет worker. Символ проверяется на входе. Часы/Session VWAP крипты — UTC 24/7; BINANCE — идентификатор поставщика, не вымышленный MIC.
