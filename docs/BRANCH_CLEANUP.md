## Автоматическая однократная процедура в Windows CI

1. Выполнить **fast-forward** `main` до Finam HEAD с новыми документами. Никакого `force`.
2. Дождаться успешного CI с реальной сборкой и тестом закрытия Windows EXE на `main`.
3. Дополнительный защищённый job проверяет, что `main` по-прежнему равен проверенному SHA Actions, и что все девять веток не изменились; текущая `codex/...` должна указывать **ровно на main**.
4. Для каждой присутствующей старой ветки создать **неизменяемую метку** `archive/2026-11-13/<original-branch>` на её tip SHA. Если метка уже есть — проверить совпадение SHA. **Только после успешного архивирования всех** разрешено удаление веток.
5. Повторно проверить SHA каждой ветки перед удалением; при изменении не удалять её. Логи job сохраняют результат. При ошибке операций GitHub/защите веток дальнейшая очистка останавливается.
6. Существующий `main` и теги архива не удалять; локальные ветки Codex также не удаляются этой процедурой.

В случае ошибки GitHub Actions остановиться и анализировать результат, не выполнять принудительный delete/force и не подменять `main` старой версией.

## Восстановление архивной ветки

Для любого тега: `git fetch origin --tags` → `git branch recovered/<name> archive/2026-11-13/<original-branch>`. Либо через GitHub Create branch at tag. Не использовать старую ветку как новую основу разработки.

## После очистки — локальный Codex

1. Убедиться, что все локальные правки закоммичены либо безопасно сохранены; ветки из местной папки **не удаляются автоматически**.
2. `git fetch origin --prune --tags`, затем `git switch main` и при чистом рабочем дереве `git pull --ff-only origin main`.
3. Если локальной `main` не было: `git switch -c main --track origin/main`.
4. В дальнейшем работать только от `origin/main`, перед переключением пользователей всегда commit + push.

**Устаревшие GitHub Actions artifacts:** версии EXE, собранные ранее в Actions, могут отображаться до истечения их retention. Архивы на Git не загружены и не являются «другими актуальными версиями». Массово удалять Actions-историю/артефакты не требуется.
