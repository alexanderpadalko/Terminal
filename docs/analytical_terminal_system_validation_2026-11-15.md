## Стресс-профиль и воспроизводимость

Среда: Windows GitHub runner; Python 3.15.2; Finam-токен **не загружался**; рыночные значения синтетические; БД временная; пользовательская SQLite не затронута.

Схема `candles(symbol, tf, ts, o, h, l, c, v, closes_at)`, ключ `(symbol,tf,ts)`. Записаны 10 640 свечей. Для каждой пары symbol/TF повторно загружены свечи с пересечением и одной изменённой исторической ценой high. После этого выявлено ровно 266 исправленных строк и 10 640 уникальных ключей. Проверено восстановление через новое соединение/сервис. Замер синтетического теста 11,868 сек; не интерпретировать как скорость реального провайдера.

Для GUI без токена проверено 3 разрешения. Чтение документации и code review были выполнены в исходном [аудите №24](https://github.com/alexanderpadalko/Terminal/issues/24). Дополнительно в ходе системной проверки найдена и устранена ошибка Qt-slot при тестовом сервисе без `api` (`flowdesk/finam_gui.py`) и исправлена уборка временного SQLite в audit tool под Windows.

## Открытые риски / условия допуска к постоянной эксплуатации

**P1 / обязательно до утверждения production readiness:**
1. Проверить 24–72 часа непрерывной работы с пользовательским токеном (нет доступа к токену в CI): reconnect, 401/403/429, задержка/пропуски обновлений, «зависшие» потоки, температура памяти/CPU.
2. Сверить реальные OHLCV/SI/Eu/экспирации/сигналы с эталоном TradingView по явным UTC-временным границам, сессиям и точному тикеру, в том числе после переподключений.
3. Сделать покрытие архивов и gap detection для старых свечей; одиночное пустое окно не доказывает отсутствие старших исторических данных.
4. Утвердить политику сигнала, когда LAST без timestamp, когда наступают выходные/закрытые сессии/неизвестные md_permissions.

**P2 / до публичного распространения:**
5. 24-часовой GUI soak (DPI 100/125/150/200%, выделение/скролл при 38×многократных событиях; Qt object lifetime).
6. Тест аварийного завершения во время SQLite-коммита, диагностика повреждения БД и сценарий резервной копии/восстановления.
7. SCA/Python зависимости + SBOM/CVE-проверка; подпись EXE Authenticode, неизменяемый релиз/контрольные суммы.
8. Benchmark графика и кэша анализа при 10+ годах исторических свечей и стресс-потоке; установить и измерять бюджет памяти/CPU/latency.

**Критерий релиза:** пока нерешённые задачи P1 существуют, приложение следует считать **успешно протестированным на offline-сценариях**, а не полностью верифицированным для безостановочной аналитики и сигналов реального времени.
