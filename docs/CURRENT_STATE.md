# FlowDesk — текущее состояние проекта

> **Рабочая карточка передачи** между ChatGPT и локальным Codex. Обновлять **с каждым завершённым изменением**. Фактический SHA всегда проверять в GitHub, т.к. документ меняется отдельным коммитом и не может достоверно ссылаться сам на себя.

## Актуальная версия

### Пять прямых источников Finam, H1 удалён (19.11.2026)

- **Последнее решение пользователя:** FlowDesk запрашивает и подписывается на готовые **M5, H4, D1, W1, MN1** Finam. Все OHLCV берутся только из источника; H4 больше **не собирается из H1/M5**, D/W/M не группируются и не переписываются. H1 исключён из кнопок, активных HTTP-запросов, WebSocket, chart-source cache и фонового архива. Ранее сохранённые H1/H4 в SQLite не стираются; старые H1 просто игнорируются.
- Новые признаки: `FinamAPI.native_all_frames=True`, `h1_only_h4_native_dwm=False`; `session_store.prepare_native_finam` публикует source H4/D/W/M с оригинальными timestamp/OHLCV, а не создаёт сессионные свечи. Сохраняется проверка времени доставки исходных закрытых баров, никаких синтетических подтверждений при отсутствии данных. Календарь сессий не вызывается для расчёта H4. `source_repair` и историческая MOEX-сборка в активном native-only пути отключены. Версии подготовки и расчётного кеша изменены.
- Индикаторы продолжают работать на M5/H4/D/W/M без изменения самих формул. Фиксированный список 4 US + 13 RU + 10 акций сохранён; обновление рейтинга, экспирации, ролловер и скринер не возвращаются. При несовпадении H4 Finam с H4 TradingView исправлять/сдвигать интервалы в приложении **нельзя** — свечи должны оставаться готовыми исходными Finam.
- Для выпуска требуется зелёный Windows CI и опубликованный EXE; тесты записи исходной H4 и запрета H1 обновлены. Старые offline/session helpers сохранены только для обратной совместимости и не вызываются в активном пути.

### Политика исходных свечей Finam (19.11.2026)

- Решение пользователя: в **активном EXE** непосредственно брать от Finam M5, H1, D1, W1, MN1; **H4 собирать только из H1**, по прежнему календарю подтверждённых физических сессий. W1 оставлен native, хотя в запросе явно перечислялись M5/H1/D/M, поскольку недельный график/скринер остаются активными.
- Программный признак `FinamAPI.h1_only_h4_native_dwm=True`. В `refresh_series` H4 заменяется на запрос H1; запросов исходного H4 и M1 нет. Из сессионного расчёта удалена зависимость H4 от M5. Уменьшенные контракты РФ используют тот же календарь H4, что остальные RTSX. Прямые D/W/M не пересчитываются из часов или дневных, не меняют Open/Close, не сдвигают выходные на понедельник. Существующие сырые H4/фьючерсные семьи в SQLite сохраняются, но не используются как активный источник.
- Native M5 выводится без локального исключения аукциона закрытия акций. Native H1 для H4 тоже может содержать сделки аукциона; без M5 их невозможно корректно вычесть. Интервалы H4 остаются по календарю: по действующей политике обычный MOEX future стартует 07:00 МСК, а не 06:00 TradingView. Неизвестные календарные дни и отсутствующее H1-покрытие не подменяются синтетическими OHLCV.
- Политика кеша анализа/сессионной подготовки обновлена: прежние пересобранные D/W/M не возвращаются при перезапуске; источники не удаляются. Исходная доставленная свеча Finam считается завершённой только при прежнем подтверждении времени и наблюдения, как в `provider_candles.native_higher_series`. Старые специализированные построители сохранены для offline/legacy-тестов, но для продуктивного Finam не вызываются.
- Тесты и итог Windows CI зафиксировать отдельно после сборки.
