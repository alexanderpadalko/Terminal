# FlowDesk — текущее состояние проекта

> **Рабочая карточка передачи** между ChatGPT и локальным Codex. Обновлять **с каждым завершённым изменением**. Фактический SHA всегда проверять в GitHub, т.к. документ меняется отдельным коммитом и не может достоверно ссылаться сам на себя.

## Актуальная версия

### Пустые внутренние свечи и цвета графика (13.11.2026)

- Исправлено: `ibEnabled` («Пустые внутренние свечи») применялся к телам только в теме `tv`, из-за чего в основном тёмном FinamWindow галочка не имела эффекта. Теперь пустая заливка внутренних свечей и контур включаются в обоих режимах, по `inside_mother_bars` на исходных high/low; тени рисуются только за пределами тела. Параметр выключения снова заполняет внутренние свечи.
- В начало настроек добавлена вкладка **«Настройки графика»**, перед «Структурное движение»: восходящие/нисходящие тело, контур и фитиль (отдельные цвета), фон графика и цвет сетки. Используется существующая компактная палитра с 0–100% прозрачностью. Значения пользовательских цветов хранятся в дополнительных необязательных полях `ApplicationSettings` (8 полей `chart_*`) как `#RRGGBBAA`. Старые JSON без этих ключей загружаются без потерь, используются палитры старых тем; SHA и 74 Pine-входа не изменяются.
- Применение, сохранение, восстановление цветов из настроек реализованы для обоих окон, включая FinamWindow (тёмная тема). Изменяются только пиксели графика, не биржевые OHLC, часы свечей, FVG и потоки. Дополнены `tests/test_tv_chart_theme.py` и `tests/test_settings_gui.py`. CI/EXE подтверждаются после успешной проверки.

### Диагностика дат экспирации США прямо в FlowDesk (13.11.2026)

- В правом списке кнопка «Диагностика экспираций США»: отчёт для всех 8 контрактов с точным тикером@MIC и статусом источника. Кнопки «Копировать отчёт» (только санитизированные статусы, никаких токенов/ответов Finam) и «Проверить повторно». Короткая метка «эксп. ?» не переполняет узкую боковую панель.
- Finam GetAsset отличает отсутствие поля `expiration_date`, пустое значение, неизвестный формат и HTTP-коды. При HTTP 400/404 пробует второй read-only `GetAsset` с **единственным** `account_id` из `TokenDetails`, если он есть; при нескольких счетах или HTTP 403 повторного запроса нет, номера счетов не сохраняются в отчёте. Поддерживаемые даты продолжают приходить из полей `future_details.expiration_date` / `expiration_date`. Достоверное содержимое ответа Finam для токена пользователя ещё не исследовано: локальный ключ не передавать в чат.
- ICE Brent LTD теперь разбирается по *заголовку колонки*, а не фиксированному индексу, с отбрасыванием противоречащих дат. CME ProductCalendar при HTTP 404 для `.json` повторяет попытку с опубликованным путём без расширения; при 403/429 не перебирает варианты и не угадывает даты. PL/PA без подтверждённого публичного календаря остаются только на Finam.
- Автоматический переход **только за один календарный день до подтверждённой даты** по MIC; не по ликвидности и не на похожие серии. Свечи/поток — только Finam; версия остаётся 0.2.26.
- Дополнены offline-тесты `tests/test_official_exchange_expiry.py` и `tests/test_finam_gui.py`. Живые CME/Finam запросы по реальным контрактам не подтверждены; перед заявлением о готовности необходимо проверить список дат на рабочей Windows-машине и статус Windows CI/EXE.

### Автопереход фьючерсов за день до экспирации (13.11.2026)

**Windows CI подтверждён:** [run #43464373282](https://github.com/alexanderpadalko/Terminal/actions/runs/43464373282), код `ccdc2d8d39b9c7f317fc945ba051827581ac1174`: **424 теста OK**, Qt Finam GUI smoke, Windows x64 PyInstaller EXE, чистое закрытие, frozen Finam executor/DNS. **Скачать ZIP (UNSIGNED):** https://github.com/alexanderpadalko/Terminal/actions/runs/43464373282/artifacts/14057224168 (49 229 341 байт, распаковывать целиком). Живое подтверждение метаданных истечения срока от конкретного Finam token и MOEX `LASTTRADEDATE` ещё нужно выполнить в установленном терминале.
- **Решение пользователя:** отменить переключение по ликвидности. Каждая серия остаётся выбранной до **одного календарного дня перед датой экспирации по местному времени биржи**. Если подтверждён следующий активный контракт той же группы/биржи с более поздней датой экспирации, FlowDesk автоматически переключает его при запуске в этот день (или позже). Досрочно по обороту/объёму больше **не** переключать; **никаких quote API вызовов для ролловера**.
- Источник даты: Finam GetAsset (`expiration_date` в Google Date, RFC3339 или protobuf Timestamp, включая вложенный `future_details`). Для RTSX при отсутствии Finam-даты используется **MOEX ISS RFUD LASTTRADEDATE** как дата окончания торгов; никаких приблизительных дат по месяцу тикера. Для фьючерсов США MOEX-даты не используются.
- На снимке все фьючерсы были «не подтверждены Finam»: ранее отсутствие даты экспирации отключало даже точный тикер из активного Finam-каталога. Теперь **точный активный тикер остаётся доступен** с явным сообщением «экспирация не подтверждена; автопереход приостановлен». Никакой замены на непроверенный контракт. Дата/активная следующая серия обязательны для автоматического перехода.
- Прежнее решение о переходе сохраняется в `~/.flowdesk/finam_roll_v1.json`; при сетевой ошибке состояние не теряется и нельзя откатиться на старую серию. Перпетуальные контракты не переключаются. 8 срочных США + 10 РФ, акции — 20.
- Акции: при старте по-прежнему обновляются по MOEX ISS (TQBR, точный `VALUE` за 20 завершённых сессий, сохранение датированного рейтинга при ошибке). Свечи/графики/WebSocket/VWAP по-прежнему только Finam; MOEX — лишь сведения для списка. Галочка HTTP управляет загрузкой свечей, не публичными справочными запросами.
- Код: `flowdesk/finam_rotation.py`, `flowdesk/finam_catalog_worker.py`, `flowdesk/moex_reference.py`; тесты `tests/test_moex_startup_roll.py`. **Живые даты экспирации Finam и MOEX нужно проверить локально с токеном; Windows CI и ZIP подтверждены выше.** Версия **0.2.26**.

### Точность цены и маркеры сессионного VWAP (13.11.2026)

**Подтверждено Windows CI:** [run 43444816664](https://github.com/alexanderpadalko/Terminal/actions/runs/43444816664), код `429a8b2161ddbe5d10ba21bec513c8c1c70c14bb`: **406 тестов OK**, Qt smoke, сборка Windows x64 EXE, корректное закрытие и frozen Finam runtime/DNS. **Скачать ZIP UNSIGNED:** https://github.com/alexanderpadalko/Terminal/actions/runs/43444816664/artifacts/14046588870 (49 207 864 байта). Живая проверка `CRZ6@RTSX` с реальным Finam asset `min_step/decimals` и визуального совпадения с TradingView ещё не выполнялась.

- **Формат цен:** единый `flowdesk/price_format.py` на `Decimal`; точность из метаданных Finam `GET /v1/assets/{ticker@MIC}`: `tick = min_step / 10^decimals`, например `CRZ6@RTSX` с шагом `0.001` → `12,456`. Формат используется на правой оси, в ярлыке последней цены, перекрестии, OHLC и ценовых подписях уровней; десятичный разделитель в графике — запятая. Старое форматирование Pine с точкой по умолчанию не меняется.
- **Finam-метаданные:** служебный read-only запрос в `FinamLoadWorker`, независимо от HTTP-галочки загрузки рыночных свечей; сетевой вызов не выполняется в GUI Qt. При недоступности карточки используется прежняя точность `0.01` без предположений по тикеру; живую точность ещё требуется подтвердить локальным Finam token.
- **VWAP-маркеры:** на правой шкале графика M1/M5: текущий `VWAP` из последнего доступного значения серии, `VWAP-1` — предыдущий завершённый anchor/session, только когда `vwapEnabled` и `vwapShowPrevious` включены и уровень существует. Цвета берутся из текущих настроек. Маркеры не подменяют last price и перекрестие; при наложении сдвигаются с соединителем к точной цене. Вне видимой Y-шкалы маркеры скрываются. Расчёт VWAP, UTC-свечи и Finam WebSocket не меняются.
- **Тесты:** `tests/test_price_axis_vwap.py` — точность 0.001/0.01/0.25/1, округление Decimal, read-only asset metadata и кэш, M5 VWAP текущий/предыдущий, пересечения меток, Qt и отключенный HTTP.

3. **Проверить реальный формат REST/WebSocket Finam**: protobuf Decimal/timestamps, маршруты авторизации, соответствие подписок, нативность M5/H4, финальные/формирующиеся свечи и границы закрытия.
4. **Проверить задержку строго по правам и наблюдениям.** Не отображать отсутствие задержки как факт по одной доступной подписке; неопределённое право не подтверждает 0 минут.
5. **Восстановить требуемые пользовательские элементы интерфейса**, утраченные при упрощении Finam-окна (расширенный правый список/панель, диагностический экспорт и индикаторные элементы) только после сверки пожеланий с текущими скриншотами.
6. Проверка H1/H4/D/W/M и FVG с TradingView на одинаковых данных, частично подтверждённая история и новая live-диагностика.
7. Улучшение обновления SQLite, инвалидации кэша и обработки разрыва потока при реальных данных; тестирование стабильного завершения EXE с активным Finam WebSocket.

## Регламент переключения

- **Перед началом:** `git status --short` → `git fetch origin` → `git switch main` → при чистом дереве `git pull --ff-only origin main`; затем прочесть `AGENTS.md` и эту карточку.
- **Перед передачей:** тесты → `docs/CURRENT_STATE.md` → commit + push → проверка remote SHA/CI. Написать следующему исполнителю «Продолжай FlowDesk», не требуется копировать чат.
- Никто не работает параллельно над одним HEAD; незапушенные изменения из локального Codex в GitHub не видны.
- **Версию 0.2.26 не повышать** без прямого указания пользователя.
