## Актуальная версия

### Исправления после первой пользовательской проверки Finam, 13.11.2026

- Версия остаётся **0.2.26**. База изменений — `78079d6`.
- Устранена подтверждённая пользователем ошибка `lazy import`: Finam worker вызывает общий bootstrap executor до `asyncio.run` / `to_thread` / DNS. CI теперь дополнительно запускает готовый EXE в безопасном режиме `--check-finam-runtime` и проверяет executor + localhost DNS без токена.
- Исправлен реальный формат WebSocket: `payload` бывает JSON-строкой, Decimal — объектом `{value: ...}`. Ранее это вызывало AttributeError и циклическое переподключение уже после handshake.
- Справочник `/v1/assets/all` вернул AAPL/MSFT/NVDA/TSLA с MIC **XNGS**, а не XNAS. Исправлены примеры, выбор MIC и сохранённый выбор этих четырёх старых примеров. Произвольные тикеры автоматически на другую площадку не переводятся.
- При смене тикера/ТФ старый график очищается; запоздавшие результаты, ошибки и прогресс другого запроса не заменяют текущий экран. Ошибка выбранного инструмента больше не оставляет SBER под выбранной TSLA.
- HTTP-ошибки показывают понятную причину без тела ответа/секретов. Если выбранный ТФ недоступен и его нет в кеше, загрузка останавливается сразу; неполное обновление сохранённого архива отмечается явно.

## Текущие функциональные договорённости

| Область | Решение |
| --- | --- |
| Данные | **Только Finam Trade API**; без активного MOEX ISS+ DEMO или TRANSAQ |
| Авторизация | Режим «Просмотр»; локальный secret key → временный JWT; без торговых операций |
| Поток | `wss://api.finam.ru/ws` для котировок/свечей; `Авто` включает поток |
| HTTP | Включается отдельной галочкой только для рыночной REST-истории/восстановления; запросы авторизации разрешены всегда |
| Символ | `тикер@MIC` (SBER@MISX, AAPL/TSLA@XNGS, IBM@XNYS — MIC из справочника, не гарантия доступа) |
| Свечи | M1, M5, H1, H4, D1, W1, MN1; время начала свечи исходное; сохранять отдельно в `~/.flowdesk/finam_candles_v1.sqlite3` |
| Анализ | Структурная ломаная, BOS/CHOCH/MAX/MIN, IDM, потоки №1–3, H1-проекция на M1/M5, FVG и VWAP по v2.11 |
| Интерфейс | Полный логотип FD/FLOWDESK, плавный график, 7 ТФ, правый выбор инструмента, тёмное оформление |

## Что подтверждено

- База Finam проходит **346 автоматических тестов** на Windows, включая адаптеры с имитированными ответами, регрессии старого движка, открытие GUI без токена и корректный выход из упакованного EXE.
- Правила хранения секретов, привязки HTTP-политики и отдельного SQLite предусмотрены в коде.
- Исправления ускорения графика, расчётов и Windows-активации/закрытия перенесены через историю ветки до Finam.
- **Подтверждены живым Finam-токеном после базы 346 тестов:** история H1 и потоковые снимки TSLA@XNGS по всем семи ТФ, как описано выше. **Не подтверждены:** фактическая задержка, длительная доставка новых свечей, полнота истории, биржевые сессии США и полный паритет TradingView. Успешная сборка EXE этого не доказывает.
- Поддержка сохранённой MOEX-диагностики **не означает**, что MOEX остаётся текущим поставщиком.

## Открытые технические задачи

1. **Живая проверка подключения к Finam на компьютере пользователя** без передачи ключа в чат: JWT, подписки, права MIC, timestamp последней сделки и свечей, ошибки, возможное ограничение каналов.
2. **Проверить длительный Finam-сеанс в Windows frozen EXE**: вызов `prepare_asyncio_runtime()` добавлен; CI проверяет executor/DNS готового EXE без ключа. Это не заменяет живую сетевую проверку упакованного EXE с локальным токеном.
3. **Проверить реальный формат REST/WebSocket Finam**: protobuf Decimal/timestamps, маршруты авторизации, соответствие подписок, нативность M5/H4, финальные/формирующиеся свечи и границы закрытия.
4. **Проверить задержку строго по правам и наблюдениям.** Не отображать отсутствие задержки как факт по одной доступной подписке; неопределённое право не подтверждает 0 минут.
5. **Восстановить требуемые пользовательские элементы интерфейса**, утраченные при упрощении Finam-окна (расширенный правый список/панель, диагностический экспорт и индикаторные элементы) только после сверки пожеланий с текущими скриншотами.
6. Проверка H1/H4/D/W/M и FVG с TradingView на одинаковых данных, частично подтверждённая история и новая live-диагностика.
7. Улучшение обновления SQLite, инвалидации кэша и обработки разрыва потока при реальных данных; тестирование стабильного завершения EXE с активным Finam WebSocket.

## Регламент переключения

- **Перед началом:** `git status --short` → `git fetch origin` → `git switch main` → при чистом дереве `git pull --ff-only origin main`; затем прочесть `AGENTS.md` и эту карточку.
- **Перед передачей:** тесты → `docs/CURRENT_STATE.md` → commit + push → проверка remote SHA/CI. Написать следующему исполнителю «Продолжай FlowDesk», не требуется копировать чат.
- Никто не работает параллельно над одним HEAD; незапушенные изменения из локального Codex в GitHub не видны.
- **Версию 0.2.26 не повышать** без прямого указания пользователя.
