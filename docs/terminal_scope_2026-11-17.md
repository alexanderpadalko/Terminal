# Объём терминала после упрощения — 17.11.2026

По прямому решению пользователя: убрать H1/M1 из пользовательской логики и терминала, не рисовать потоки на M5, убрать BOS/CHOCH/MAX/MIN/IDM. Уточнения: H1 сохранить только как скрытый источник свечей, красно-зелёную ломаную оставить.

| Область | Рабочее поведение |
|---|---|
| Графики | M5/H4/D1/W1/MN1, начальный H4 |
| H1 | Сырые OHLC для прежней сборки H4/D/W/M, без Analysis/сводки/FVG-контекста |
| M1 | Нет HTTP/WS/архивных заданий/рабочего чтения, старые строки базы сохраняются |
| Потоки, сводка, скринер | H4/D/W/M |
| M5 | Свечи, ломаная, FVG и VWAP; пустые flows/pairs, без H1-проекции, уровней и диагностики |
| Market structure | Нет отдельного market-state replay, BOS/CHOCH/MAX/MIN/IDM отрисовки и настроек |
| Старые предпочтения | M1/H1 автоматически заменяются H4 |

`terminal_policy.py` разделяет видимые интервалы, источники и аналитические интервалы. Продуктовые `view`/`scan_one` используют эту политику; `analyze_cached` использует её по умолчанию. Раздельный policy key не позволяет повторно использовать старый расчёт M5 с H1-проекцией. PairEngine на M5 не создаётся; checkpoint поддерживает пустое состояние пары.

Legacy reference/CSV utility-код и 74-полевой manifest оставлены для офлайн-регрессий и чтения старых настроек. Они не активируют удалённые функции в пользовательском EXE. В активном диалоге нет market-группы и настроек M1/H1, при сохранении их логические флаги выключены.

Сборка H4, аукционная/календарная политика, цены и список 22 инструментов не изменялись. Тест сравнивает candles/segments/flows/pairs/FVG/liquidity audit H4/D/W/M с прежним расчётом. Удаление работы уменьшает вычисления и удерживаемые объекты; процент снижения CPU/RAM всего EXE не измерялся.

Локальная проверка: 772 теста за 46.956 с, один штатный skip; затем 10 профильных проверок успешны, включая пустую M5-диагностику и отметку версии движка. Системный/расширенный аудит, DPI 100/125/150/200%, compileall и pip check успешны. Windows CI и EXE будут зафиксированы после сборки. Сводное доказательство: `terminal_scope_2026-11-17.json`.
