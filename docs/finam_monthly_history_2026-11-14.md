# Реальное количество месячных свечей Finam — 14.11.2026

Проверено через действующий локальный ключ Finam, не по числу свечей в SQLite. Рыночные данные получены только из Finam. Секреты, JWT и номера счетов не сохранялись. Приложение, его настройки, ролловер и SQLite не изменялись.

Срез истории: **14.11.2026 22:04:48 МСК** (`2026-11-14T19:04:48.291685Z`). У всех 38 инструментов последняя полученная свеча относится к ноябрю 2026 и ещё не закрыта. Столбец «Закрытых» поэтому на единицу меньше общего количества.

## Метод

1. Точные тикеры/MIC проверены через активный Finam-каталог. Серии взяты из текущего сохранённого выбора фьючерсов; акции — из текущего сохранённого топ-20. Контракты не склеивались и не заменялись.
2. Запрос `TIME_FRAME_MN` за последние 1825 суток выполнен для каждого из 38 инструментов и сверён с объединением пяти годовых запросов: количества совпали. Обычно это 60 свечей акций, но это только выбранный интервал.
3. Отдельный запрос с 1990 года до текущей даты Finam отклонил HTTP 400. Затем выполнены последовательные запросы интервалами не длиннее 1825 суток, с продвижением назад и объединением по точному timestamp без заполнения пропусков. Проход останавливался на первом пустом пятилетнем интервале; его граница и каждый ответ сохранены в JSON. Полное отсутствие данных раньше проверенной пустой области этим не доказывается.
4. Между запросами пауза 0,6 с; при 429 предусмотрена остановка. Итоговый проход всех 38 инструментов прошёл без HTTP-ошибок. Это наблюдённое количество переданных свечей в проверенных интервалах, а не обещание неизменного максимума API.

## Главный результат

**У Finam нет подтверждённого общего ограничения месячной истории в 60 свечей.** Документация Bars указывает пять лет для TIME_FRAME_MN, но реальные запросы старых пятилетних интервалов вернули, например, SBER с июня 1999 года (330 свечей) и LKOH с мая 1997 года (355 свечей). Нельзя приравнивать размер запрашиваемого окна к общей доступной глубине.

В `flowdesk/finam_screener.py:_backfill_higher_history` текущий cutoff `now - DEPTH_DAYS[MN1]` ограничивает всю дозагрузку пятью годами. Именно это ограничивает получение старого месячного контекста акций в терминале; сохранённые более старые свечи при этом не удаляются. В этой проверке код загрузки не менялся.

У SiZ6 получены 23 закрытых месяца, у EuZ6 — 15. На момент измерения действовал порог скринера MN1=30; поэтому дополнительные запросы старых периодов этих серий не устраняли блокировку. Позднее 14.11.2026 пользователь прямо отменил все фиксированные минимумы свечей: теперь готовность определяется опубликованным потоком и подтверждённым рабочим FVG. Эта отмена не добавляет свечей в архив и не изменяет приведённые результаты измерения.
