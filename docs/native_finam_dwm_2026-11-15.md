## Основание и сохранённая версия

Пользователь выбрал вариант 1: готовые D1/W1/MN1 Финама должны участвовать в графике и индикаторе; недостаток мелкой истории или праздничного календаря не является основанием исключать готовый период. Перед работой чистая локальная `main` обновлена с d626959 до актуальной **67ae255** через fetch/pull. Изменения пользователя сохранены: **30 инструментов**, ТОП-10 акций за 20 завершённых сессий, порядок КРИПТА → US futures → RU futures → RU shares, отсутствие текстового поиска, центрирование последней свечи и рабочий FVG **v2.14** поверх числовой базы v2.11/74 настроек. Эти модули и pinned Pine не редактировались.

## Что изменено

- `provider_candles.py`: явная политика **finam-native-dwm-1**. D/W/M принимаются из собственного Finam TF целиком, с исходными timestamp/OHLCV. Нет заполнения пропусков сессионными свечами, замены отдельных месяцев и переключения источника внутри истории TF.
- `session_store.py`: H1/H4 продолжают прежний сессионный путь; рассчитанные D/W/M остаются **контрольным результатом**, а не входом индикатора. `issues` основного набора отделены от `control_issues`. Неизвестный календарь/неполное нижнее покрытие и ожидаемое расхождение сессионного режима не исключают native D/W/M. Ошибка валидации контрольных нижних интервалов также не стирает готовый native архив. Данные Binance используют прежнюю UTC-политику.
- Политика включена в ключ кэша. Старый сессионный кэш с единственным MN1 не может быть повторно использован после обновления. Исходная SQLite сохраняется; новые значения источника обновляются только обычным upsert, без удаления архива.
- `finam_market.py`: HTTP запрашивает непосредственно D1/W1/MN1 со своими TTL; H4 требует H1/M5, не заставляет D/W/M проходить проверку нижнего покрытия. Метаданные D/W/M — `FINAM_NATIVE_CANDLES`, H1/H4 — `SESSION_CANDLES`. Запросы одного symbol/TF по-прежнему объединены, старый архив сохраняется, контроль рабочего окна раз в сутки, обычный overlap последних трёх свечей.
- `finam_api.py`: Finam WebSocket снова подписывается на W1/MN1 наряду с M1/M5/H1/D1 — один прежний канал, шесть TF. При reconnect восстанавливаются действительные исходные периоды, а не неиспользуемая native H4. H4 остаётся сессионным.
- `finam_screener.py`: тот же подготовленный набор и тот же FVG v2.14. Недоступный H1 больше не блокирует анализ доступных D/W/M при пригодном LAST. Месячный close не используется вместо LAST. Без пригодного LAST/M1/H1 цена остаётся недоступной. Архивный этап возобновляет native W/M/D и отдельно H4-источники: не более **пяти** дополнительных запросов на инструмент за проход (до четырёх native + одно сессионное окно). Курсоры сохраняются, очередь/приоритет графика прежние.
- `diagnostics_log.py`: `D1_control`/`W1_control`/`MN1_control` отделены от ошибок основного набора. Записываются только разрешённые коды/количества/политика, без OHLC, исключений, URL, токенов и счетов. Контрольный расчёт выполняется существующими фоновыми исполнителями; новых панелей/настроек в UI нет.

## Закрытые свечи и старый кэш

Сохраняются проверки timestamp, конечных чисел, допустимого OHLCV, сортировка/дедупликация и раздельные источники Finam/Binance. Формирующаяся native свеча не становится подтверждённой лишь при переводе часов: известный снимок до nominal close должен быть повторно получен после окончания. Идентичный HTTP-снимок тоже подтверждает источник. Обычный stream не переписывает запечатанную свечу; HTTP-коррекция разрешена.

Для legacy-архива без времени наблюдения сохраняются прошлые периоды, когда в кэше уже присутствует следующий период, наступивший к моменту расчёта. Непроверенная правая граница требует ограниченного штатного HTTP-обновления; это относится к состоянию исходного снимка, **не к полноте календаря/минутной истории и не к минимальному числу свечей**. Известный незавершённый снимок не объявляется закрытым из-за следующей записи. Если такой разрыв окажется внутри истории, данные по его сторонам не склеиваются в ложную соседнюю пару для FVG.

Времена окончания native D/W/M остаются существующими консервативными окончаниями интервалов Finam-адаптера; точное биржевое закрытие/совпадение с сессионной моделью не утверждается. При отсутствии native TF не подставляется собственный расчёт под тем же обозначением. Формирующийся снимок, полученный позже заданного asof, не используется задним числом.
