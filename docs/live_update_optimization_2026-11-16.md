# Нагрузка во время работы, 16.11.2026

После исправления CR внутренний подтверждённый H1-блок стал длиннее. Обновление его последней незакрытой свечи заново прогоняло pinned replay через весь этот блок. Кроме того, ReferenceContext удерживал сам себя через сохранённые callbacks; завершённые расчёты ждали циклического GC в GUI-потоке.

Изменения:

- `replay_checkpoint.py` хранит изолированное состояние исходных Structure/FVG/Pair/PinnedFlow engines перед незакрытым суффиксом. Повторный расчёт исполняет прежние шаги только для суффикса. Исторические свечи/FlowState не копируются глубоко, изменяемые engines/FVG/контекст копируются; прежний Analysis не мутирует.
- Возобновление допустимо при точном совпадении всего закрытого префикса, числа закрытых свечей, settings/tick/TF и потребляемых закрытых старших свечей/потоков/пар, без движения asof назад. Иначе полный replay. Закрытие свечи/исправление старых котировок/изменение настроек или источника не обходят проверку. Раздельные history-блоки сохраняют локальный checkpoint и глобальные индексы; полностью закрытые ряды checkpoint не удерживают.
- Закрытая часть capture audit переиспользуется только при той же проверке источников; незакрытый суффикс сохраняет SOURCE_NOT_CLOSED. M1/M5 H1-проекция и market-state replay выполняются прежним методом: числовые формулы, BOS/CHOCH и публикация FVG не изменены.
- Reference helpers/formatters/sections используют слабую ссылку на свой context. Завершённый replay освобождается без искусственного цикла. GUI-thread GC и его Qt-безопасность прежние.
- LRU тяжёлых расчётов: **4 записи/100000 единиц вместо12/250000**, активный график закреплён. Это бюджет вычислительных объектов, не абсолютный предел RAM. Исходная история/график не урезаются; вытеснённый другой график рассчитывается при открытии.

Медиана CR **0.8454→0.0816с (10.4×)**, SBER **0.2023→0.0295с (6.9×)**.
