# CRZ6: первое открытие D/W/M — 16.11.2026

На скриншоте после обновления D1 CRZ6 не загружался. Read-only проверка пользовательской базы подтвердила: **303 raw D /75 W /18 M**, но `MOEX_DAILY_TRADING_v1` не запускался; staging `incomplete_daily_coverage`. Проверенный календарь был доступен. То же отсутствие начального progress наблюдалось у Si.

Загрузчик графика требовал законченной подготовки архива, а её запуск находился только во второй фазе скринера после первичной проверки всех 30 активов. Прежний аудит подготавливал историю прямым вызовом backfill до проверки потребителей: правильность готовых свечей была подтверждена, первый запуск приложения — пропущен.

## Изменение

`FinamMarketService.view(..., allow_http=True)` для выбранного российского D/W/M проверяет общий `archive_ready` и запускает нужную ограниченную D1-подкачку внутри отменяемого worker графика. До четырёх архивных окон по 180 дней, прежние курсоры и общая очередь Finam; незавершённая работа продолжается после отмены/перезапуска. Подготовка пересчитывает состояние после загрузки и возвращает график в том же запросе. Не требуется сначала пройти весь scanner.

Chart/scanner разделяют per-symbol bootstrap-блокировку, без блокировки SQLite на время HTTP и без дублирования архивных окон. `allow_http=False` не обращается к сети. Первопричина сбоя записывается через безопасный allowlist: HTTP/тип/TF/stage, без тела ответа, секрета или текста исключения. Ошибка подготовки больше не маскируется общим сообщением о календаре; пользовательское исключение не копирует исходный текст.

Никаких изменений OHLCV, trading date, подтверждений, W/M-префикса, правил индикатора, US Last, Binance UTC, UI, 74 настроек или версии 0.2.26. Сырой пользовательский кэш не очищается. История в тесте обновляется только в отдельной копии базы.

## Проверка

Все 20 российских активов открыты обычным **`view(D1, allow_http=True)` из неподготовленного кэша**, затем W1/MN1 при выключенном HTTP. Без прямого backfill, предварительной записи progress и scanner-прохода. Все успешны. CRZ6: **4.765 с**, **329 D /75 W /18 M**. Замер относится к этому подключению и данным; это не гарантия скорости и не полный паритет с TradingView. [Evidence](evidence/moex_first_open_2026-11-16.json).

Новые регрессии: первый запрос каждого D/W/M, публичный Qt worker, готовый кэш после перезапуска, запрет сети при cache-only, сохранение первого завершённого окна при отмене и правильное продолжение, отсутствие дублей при одновременном scanner/chart, безопасный HTTP 503 без текста исходной ошибки. Локально **694 теста** без ошибок/сбоев, 43.626 с; один subprocess-пропуск для Windows CI. Windows EXE/CI данного исправления ожидаются. Установленный EXE не заменялся автоматически.
