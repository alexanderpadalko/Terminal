# Автоматическое обновление и новые MOEX-фьючерсы — 18.11.2026

Версия приложения0.2.26. Пользователь согласовал автоматический резерв HTTP и добавление пяти фьючерсов Мосбиржи с данными Finam.

## Поведение обновлений

Ручное поле «Интервал резервного HTTP-обновления» убрано из активного Finam-терминала. Старые значения игнорируются: при запуске/применении/сбросе используется300с. Исторический CSV/MainWindow сохраняет свой старый формат настроек. Скринер имеет независимый HTTP-цикл300с; WS остаётся только у выбранного инструмента.

При resync/reconnecting/unavailable источники помечаются для восстановления; ready запускает внеочередную проверку. Если расчёт уже работает, сохраняется один pending-запрос, который выполняется после его завершения. Повторное ready одного epoch не создаёт повторной загрузки. Новая выбранная пользователем заявка имеет приоритет и сама проверяет свежесть. При HTTP-проверке накопленные потоковые свечи передаются тому же worker; найденный промежуток ремонтируется до расчёта через существующий per-source механизм. Наложения chart workers нет.

M5/H1 проверяются по300с, старшие источники сохраняют свои более длинные TTL. Обычный короткий запрос перекрывает последние три исходные свечи; полная проверка окна сохраняет суточное расписание. Периодические проверки, HTTP-скринер и reconnect используют общий coordinator/SQLite и дедупликацию. 429, таймауты, отмена и отсутствие новых данных сохраняют прежнюю обработку. Полная история не перегружается каждые5мин и не обрезается. Количественное снижение общего CPU/RAM не измерялось.
