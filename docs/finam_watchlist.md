## Настоящие символы Finam

TradingView использует, например, `RUS:SIZ2026`, тогда как торговый инструмент Финама может называться `SiZ6@RTSX`.
**Сохраняем регистр символа из каталога Finam в запросах REST/WebSocket**: `SiZ6` нельзя механически заменить на `SIZ6`, если сервер требует точного написания. Внутренний ключ сравнения при этом может быть регистронезависимым. Название **на экране не передаётся в API напрямую**. При наличии локально настроенного read-only токена FlowDesk в отдельном Qt worker получает активный справочник `GET /v1/assets/all?only_active=true` с пагинацией, проверяет тикер и MIC. US фьючерсы ищутся на MIC торговых площадок CME/COMEX/NYMEX/ICE; российские — `RTSX`. Двойное совпадение, неподходящая площадка, другая серия или отсутствие символа => инструмент неактивен с явным сообщением. Никаких поручений не отправляется.

Если Finam не предоставляет конкретную серию или нет прав аккаунта, она остаётся видимой, но открытие невозможно. Наличие в каталоге ещё не доказывает право на свечи или реальное время; проверка выполняется при загрузке графика.

HTTP-галочка продолжает разрешать только REST-загрузку **рыночных свечей**. Служебный read-only справочник — метаданные инструмента, а не котировки, и может запрашиваться независимо от галочки. Источником **рыночных свечей и котировок ГРАФИКА** остаётся только Finam Trade API. Для обновления СПИСКА инструментов используется публичный read-only MOEX ISS: точный дневной оборот TQBR акций VALUE и статистика VOLTODAY/VALTODAY для российских фьючерсов RFUD.

## Автоматическая проверка оборотов

При запуске FlowDesk использует уже существующий точный расчёт MOEX ISS за 20 завершённых торговых сессий TQBR. Кэш ускоряет повторную загрузку. Только после полной проверки новый рейтинг заменяет предыдущий. Ошибки и дату прошлого рейтинга видно в интерфейсе.

Для российских фьючерсов источник оборота и объёма — MOEX ISS RFUD (VOLTODAY, VALTODAY). Для US futures — Finam GetLastQuote (volume, turnover). Досрочный ролловер выполняется только если ОБА показателя следующего контракта строго выше текущего в той же сессии. Даты экспирации берутся из карточки Finam GetAsset, не вычисляются из месяца тикера. При отсутствии доказательств контракт не подменяется. Российские perpetual остаются постоянными.

Запросы MOEX не используются для свечей графика или как резерв Finam WebSocket. HTTP-галочка продолжает управлять только рыночной историей свечей; справочные read-only запросы для списка независимы.
