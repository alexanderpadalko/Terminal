**Российские акции (ровно 20):** первые 20 акций последнего локального рейтинга `~/.flowdesk/watchlist_v1.json`, рассчитанного прежним движком по **точному RUB-обороту за 20 завершённых торговых сессий** (TQBR, ordinary + preferred). Если проверенного локального рейтинга нет, используются первые 20 исходного `flowdesk/data/watchlist_seed.json` с явной меткой **«исходный список (без подтверждённых оборотов)»**. Отображается дата рейтинга; **при каждом запуске с настроенным токеном** рейтинг обновляется по MOEX ISS: сумма точного дневного рублёвого оборота VALUE за последние 20 завершённых торговых сессий. При ошибке сети — датированный кэш.

**Фьючерсы России (10):** `SIZ2026`, `CRZ2026`, `EUZ2026`, `EDZ2026`, `USDRUB.P`, `CNYRUB.P`, `EURRUB.P`, `MIXZ2026`, `RIZ2026`, `IRUS.P`.

Фьючерсы проверяются на экспирацию при запуске и **за один календарный день до неё (в местной дате биржи)** переключаются на следующую подтверждённую действующую серию с той же MIC. Объём и оборот для переключения больше не используются. Без подтверждённой даты следующий контракт не выбирается автоматически; если точный текущий тикер есть в каталоге, он остаётся доступен с предупреждением. Перпетуалы не переключаются. Все три группы сохраняются.

## Настоящие символы Finam

TradingView использует, например, `RUS:SIZ2026`, тогда как торговый инструмент Финама может называться `SiZ6@RTSX`.
**Сохраняем регистр символа из каталога Finam в запросах REST/WebSocket**: `SiZ6` нельзя механически заменить на `SIZ6`, если сервер требует точного написания. Внутренний ключ сравнения при этом может быть регистронезависимым. Название **на экране не передаётся в API напрямую**. При наличии локально настроенного read-only токена FlowDesk в отдельном Qt worker получает активный справочник `GET /v1/assets/all?only_active=true` с пагинацией, проверяет тикер и MIC. US фьючерсы ищутся на MIC торговых площадок CME/COMEX/NYMEX/ICE; российские — `RTSX`. Двойное совпадение, неподходящая площадка, другая серия или отсутствие символа => инструмент неактивен с явным сообщением. Никаких поручений не отправляется.

Если Finam не предоставляет конкретную серию или нет прав аккаунта, она остаётся видимой, но открытие невозможно. Наличие в каталоге ещё не доказывает право на свечи или реальное время; проверка выполняется при загрузке графика.

HTTP-галочка продолжает разрешать только REST-загрузку **рыночных свечей**. Служебный read-only справочник — метаданные инструмента, а не котировки, и может запрашиваться независимо от галочки. Источником **рыночных свечей и котировок ГРАФИКА** остаётся только Finam Trade API. Для обновления СПИСКА инструментов используется публичный read-only MOEX ISS: точный дневной оборот TQBR акций VALUE и, при необходимости, последний торговый день `LASTTRADEDATE` российских фьючерсов RFUD.

## Резервные календари CME / ICE и ошибки Finam

В новой версии для каждого доступного фьючерса США запрос Finam GetAsset проверяется на полноту даты. Если поле отсутствует или GET вернул ошибку, всплывающая подсказка выводит безопасный признак причины (`Finam GetAsset: HTTP 403/404/429` либо `дата отсутствует`); secret/JWT и тело ответа не показываются.

При отсутствии Finam-даты FlowDesk в фоне пытается прочитать официальный календарь **Last Trade Date**: CME Group ProductCalendar/Future для NQ, ES, GC, SI и ICE Brent product 219 для BRN на IFEU. Календарные даты используются только при точном совпадении контракта, месяца и года; другие типы событий (опционы, расчёт, first notice) исключаются. Если публичный интерфейс CME не ответил или формат отличается — статус «дата не подтверждена», автопереход не выполняется. **PL, PA, NG** пока без подтверждённых URL ProductCalendar; для них остаётся Finam или сообщение об ограничении. Полный защищённый CME Reference Data API требует лицензированного доступа. Реальную работоспособность открытых календарей следует проверить в пользовательской сети.

**Правило:** перенос только за один календарный день перед подтверждённой датой истечения (по биржевому MIC). Активный контракт без даты разрешено открыть, но переход запрещён. Фьючерсы РФ — Finam с резервом MOEX LASTTRADEDATE. Акции РФ продолжают обновляться через MOEX VALUE. Свечи/котировки графика только Finam.

Официальные календари:
- https://www.cmegroup.com/tools-information/calendars/expiration-calendar.html
- https://www.cmegroup.com/trading/market-tech-and-data-services/cme-reference-data-api.html
- https://www.ice.com/products/219/brent-crude-futures/expiry

## Обновление акций и календарь экспирации

При запуске FlowDesk пересчитывает топ-20 российских акций из публичного MOEX ISS по фактическому дневному обороту `VALUE` TQBR за последние 20 завершённых торговых сессий. При сбое используется ранее сохранённый рейтинг с датой.

Для фьючерсов Finam GetAsset сообщает дату экспирации: поддерживаются дата `year/month/day`, ISO timestamp и объект `seconds/nanos`, в том числе внутри вложенного `future_details`. Для российских RTSX, если Finam не сообщил дату, проверяется официальный `LASTTRADEDATE` через MOEX ISS RFUD (последний торговый день). Для американских контрактов даты MOEX не используются.

**Правило:** если местная календарная дата площадки достигла `expiry - 1 день`, выбрать следующую доступную в Finam серию той же группы и MIC с проверенной более поздней датой экспирации. Объёмы/обороты, даже если следующая серия ликвиднее, не вызывают досрочный ролловер. Для неизвестной экспирации точный активный контракт остаётся доступен, но автопереход запрещён; если следующий контракт не подтверждён, старый не подменяется. У вечных фьючерсов даты и ролловера нет. Сохранённая ранее выбранная серия не теряется при временной ошибке каталога.

MOEX не используется для свечей графика или как резервный фид Finam WebSocket. Галочка HTTP управляет только историческими свечами; служебные read-only запросы для списка выполняются независимо.
