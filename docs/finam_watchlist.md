## Настоящие символы Finam

TradingView использует, например, `RUS:SIZ2026`, тогда как торговый инструмент Финама может называться `SiZ6@RTSX`.
**Сохраняем регистр символа из каталога Finam в запросах REST/WebSocket**: `SiZ6` нельзя механически заменить на `SIZ6`, если сервер требует точного написания. Внутренний ключ сравнения при этом может быть регистронезависимым. Название **на экране не передаётся в API напрямую**. При наличии локально настроенного read-only токена FlowDesk в отдельном Qt worker получает активный справочник `GET /v1/assets/all?only_active=true` с пагинацией, проверяет тикер и MIC. US фьючерсы ищутся на MIC торговых площадок CME/COMEX/NYMEX/ICE; российские — `RTSX`. Двойное совпадение, неподходящая площадка, другая серия или отсутствие символа => инструмент неактивен с явным сообщением. Никаких поручений не отправляется.

Если Finam не предоставляет конкретную серию или нет прав аккаунта, она остаётся видимой, но открытие невозможно. Наличие в каталоге ещё не доказывает право на свечи или реальное время; проверка выполняется при загрузке графика.

HTTP-галочка продолжает разрешать только REST-загрузку **рыночных свечей**. Служебный read-only справочник — метаданные инструмента, а не котировки, и может запрашиваться независимо от галочки. Источником свечей/котировок остаётся **только Finam Trade API**. Список акций читает старую локальную базу, но **не обращается к MOEX по сети**.

## Ограничение актуализации топ-20

Текущий Finam REST предоставляет поле `turnover` для последней котировки, но не отдельную историческую таблицу точного дневного оборота **всех** акций за последние 20 завершённых сессий. Текущий оборот одного дня или оценка `OHLC×volume` — это не прежняя методика ранжирования. Нельзя выдавать их за подтверждённый рейтинг 20 сессий. Следующая отдельная задача — спроектировать накопление точных дневных оборотов из Finam либо получить разрешение на использование первичного публичного рейтинга MOEX *только для состава списка*. Без этого ранжирование может устаревать.

## Время площадок фьючерсов

Для RTSX биржевое время — Москва, для XCME — Chicago, для XCEC и XNYM — New York, для IFEU — London. Автоматические летние/зимние переходы обеспечиваются IANA ZoneInfo. Календарная граница дня для Session VWAP фьючерсов **не равнозначна** границе реальной вечерней торговой сессии: требуется отдельно проверять `/v1/assets/{symbol}/schedule` и часы каждого контракта. Правило VWAP 04:00–20:00 ET относится **только к американским акциям**, не к фьючерсам.
