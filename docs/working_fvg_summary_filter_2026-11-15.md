# Подсветка рабочего FVG и несформированные потоки

15.11.2026, версия **0.2.26**, исходная общая версия **f88a533**.

## Согласование сводки

`summary_rows` самостоятельно проверял guard по закрытым границам потока, а отрисовка и скринер вызывали `working_zone`. Последний разрешает расширение границ подтверждённого эпизода по развивающейся свече, сохраняя направление и исходный guard; проверяет время формирования guard и его существование в исходной серии. Разные проверки могли расходиться: видимая рабочая зона H4 не подсвечивалась в сводке при расширении границ. Обратный случай — ошибочная подсветка guard до закрытия формирующей его свечи.

Сводка теперь использует тот же `working_zone`. Цвет обозначает попадание цены в **текущий рабочий FVG**, inclusive по границам; стрелка направления остаётся независимой. Пробитая/старая зона и весь диапазон потока не дают сигнал. Алгоритм FlowEngine, выбор guard и исходные OHLC не менялись. Два новых теста публикации до изменения падали, после прошли; один сравнивает отрисовку, сводку и скринер при одинаковых времени/цене, другой исключает преждевременную подсветку.

## Скрытие несформированных потоков

Пользователь подтвердил: учитывать выбранные периоды, при нескольких оставить инструмент по действующему сигналу любого из них. Дополнительно указал не писать в таблице, что поток не сформирован.

- В активном фильтре None с причиной «поток ещё не сформирован» или «нет подтверждённого состояния» исключается из причин для раздела «НЕТ ДАННЫХ».
- Если на других выбранных TF нет сигнала/реальной ошибки источника, строка не показывается. Если сигнал есть, строка и её действующие цветные TF-плашки остаются, без пояснения о несформированном периоде.
- Отсутствие свечей, доступа, цены, незавершённая проверка и прочие сбои остаются отдельными нейтральными состояниями; они не становятся SHORT.
- Без активного фильтра сохраняется обычный список всех 40 без TF-плашек. Фильтр не закрывает выбранный график. Числовые минимумы свечей не возвращены; вычисления/данные не менялись.

## Проверка Si и пределы

Использовалась согласованная SQLite backup из источника mode=ro в отдельную тестовую базу, без HTTP, ключа и изменения рабочего профиля. История: 447 H1 / 307 H4. Срез **15.11.2026 16:03:17 МСК**, последняя H1-цена **83030**. И у H4 родительского графика, и у H4 источника сводки guard **82930–82947**, `guard_broken=true`; закрытие H4 **14.11.2026 20:00 МСК = 82976**. В этом срезе `working_zone=None`, нет текущей H4 зоны в плане отрисовки и H4=0 в сводке/скринере. Широкий диапазон потока **82538–83811** не заменяет FVG. H4-сигнал для этого среза не добавлялся принудительно.

Этот срез позже пользовательского изображения с ценой 83034; тождество всех входов/настроек именно в момент изображения не установлено. Обнаруженное расхождение двух проверок сводки воспроизведено отдельно детерминированными тестами. На первом пользовательском изображении также указано «Проверка ещё не запускалась» и ни один фильтр не активирован; такой список по прежнему правилу показывает инструменты без цветных TF-плашек.
