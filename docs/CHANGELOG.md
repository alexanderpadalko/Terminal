# FlowDesk — журнал существенных изменений

> Точный полный журнал отдельных коммитов хранится в **Git**. Здесь перечислены только продуктовые этапы. Текущую готовность проверять по `docs/CURRENT_STATE.md` и Actions.

## 0.2.26 — Finam Trade API only (13 ноября 2026)

- Цены в Chart теперь форматируются по реальному шагу Finam (`min_step / 10^decimals`) через Decimal и десятичную запятую; на правой оси добавлены маркеры текущего и предыдущего VWAP с защитой от наложений. Все 74 настройки, расчёты и номер версии сохранены.

- Подготовлен безопасный выпуск Windows EXE с Microsoft Artifact Signing через OIDC и обязательной проверкой Authenticode + RFC3161. Пока отсутствует проверенный сертификат, все новые артефакты маркируются UNSIGNED. Версия 0.2.26 без изменений.

- Исправлено разделение VWAP на несоединённые сегменты разных сессий, а также двойное визуальное выделение таймфреймов (рамка фокуса на 1м при активном 5м); расширена сессионная привязка VWAP до GC/SI COMEX и PL/PA/NG NYMEX — новый торговый день 18:00 ET, нет сброса в 00:00 ET. Добавлены проверки границ сессии и GUI.

- Для NQ/ES на CME Globex исправлена торговая граница Session VWAP: **18:00 ET / 17:00 CT**, пауза 17:00–18:00 ET, непрерывность через полночь. Добавлены регрессии DST, выходных и Qt-смены NQ/ES/GC; остальные инструменты без изменения.

- Новый строго ограниченный список: восемь срочных контрактов США, старый топ-20 российских акций за 20 сессий (с датой), десять указанных российских фьючерсов. Тикер@MIC каждого фьючерса подтверждается активным Finam-каталогом; неподтверждённые серии не подменяются. Рейтинг акций не объявляется актуальным без проверенной истории оборота.


- Время всех графических меток Finam привязано к бирже по MIC и IANA, а сессионный VWAP акций США охватывает **04:00–20:00 ET** с премаркетом и постмаркетом; не сбрасывается в 00:00 МСК. Отдельная проверка real-time свечей Finam остаётся открытой.

- После пользовательской проверки исправлены frozen `lazy import`, JSON-строка `payload` и Decimal-объекты живого WebSocket.
- Встроенные AAPL/MSFT/NVDA/TSLA исправлены на MIC XNGS по реальному справочнику; старый сохранённый выбор этих примеров мигрирует.
- Неудачная смена инструмента очищает прежний график; запоздалые результаты другого ТФ/тикера игнорируются. Ошибки загрузки и частичное обновление архива показываются явно.
- Реально получены 176 H1 TSLA@XNGS и семь WebSocket-снимков без рыночного HTTP. Новые свечи в торговой сессии, фактический лаг и паритет Pine этим не подтверждаются.
- Добавлена проверка executor/DNS через Finam worker в готовом Windows EXE, без ключа и внешней сети.
- Код `ed76412`: Windows CI `43392593326` успешно прошёл 355 тестов, сборку, WM_CLOSE и frozen Finam runtime; ZIP `14020748530`. Отдельная последующая запись результатов затрагивает только документацию.

- Выбран единственный активный источник котировок — **Finam Trade API**, независимый от установленного TRANSAQ.
- Новый Windows интерфейс, тикер@MIC, локально сохраняемый read-only secret key, JWT, WebSocket на QUOTES/BARS и HTTP-история по отдельной галочке.
- Отдельная SQLite для Finam, базовые тесты парсинга/permissions/гейтинга HTTP.
- Исправлено закрытие SQLite на Windows; добавлен JWT Authorization header WebSocket.
- Windows CI для базы `294329e`: **346 тестов**, упакованный EXE, проверка закрытия.
- **Не доказаны** реальный API-сеанс, задержка котировок, полнота свечей и визуальный паритет TradingView. Проверка с локальным ключом — следующая задача.
- В том же номере версии консолидированы документация и основной branch `main` для последовательной работы ChatGPT и Codex. PR №1 объединён; 9 старых веток архивированы тегами и удалены после успешного Windows CI `43317493383`.
