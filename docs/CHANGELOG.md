# FlowDesk — журнал существенных изменений

## 18.11.2026 — память при открытии большого графика

- Кэш расчётов кодируется и сжимается порциями. Ограничение размера проверяется во время записи, слишком большой снимок не обрабатывается вновь при каждом изменении текущей свечи. При чтении данные восстанавливаются по записям без второго полного дерева JSON в памяти.
- FVG хранит две свечи, необходимые для следующего шага, с сохранением абсолютных индексов. Выходные зоны, структура и история графика сохраняются.

## 18.11.2026 — обновление хвоста и режим свёрнутого окна

- При обычном обновлении график читает из SQLite изменившийся хвост исходных свечей и использует сохранённый префикс. Старая коррекция и новая отметка подтверждения тоже учитываются. При пропуске ревизии выполняется полное чтение.
- При сворачивании окно откладывает обычный пересчёт графика до восстановления. Фоновое сохранение свечей, проверка пропусков, резервный HTTP и скринер продолжают работу.

## 18.11.2026 — автоматический резерв HTTP и расширение Мосбиржи

- Резервная сверка выбранного графика раз5мин, вне очереди при восстановлении/пропуске; ручное поле убрано. Занятый worker не теряет запрос сверки, одинаковые ready не запускают дубликаты.
- Добавлены IRUS.P/IMOEXF, золото GD, серебро SV, Brent BR и природный газ NG на RTSX через Finam. Теперь27инструментов; существующие зарубежные контракты сохранены отдельно. Алгоритм H4 и правила цен не менялись.

## 17.11.2026 — Finam-only, ED, дневной рейтинг и постоянные расчёты

- Крипта и Binance отключены в активном терминале; ED евро/доллар Мосбиржи добавлен через Finam. Старые базы сохранены, список22:4US/8RU/10акций.
- ТОП-10 MOEX при запуске один раз за календарный день МСК с сохранением результата и блокировкой одновременных запусков; без повторного внутридневного опроса.
- Скринер только HTTP раз/5мин с защитой снимка от WS; WebSocket только открытого инструмента, без перекрытия при переключении. Косметические настройки не перезапускают скринер, второй архивный scan-проход убран.
- Ограниченный безопасный JSON/zlib-кэш расчётов на диске, проверка версии/данных/настроек/шага цены, продолжение на новых свечах. Точные общие расчёты не дублируются. Исходная история/H4/формулы сохранены.
