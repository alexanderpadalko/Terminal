# FlowDesk 0.2.26: HTTP только с разрешения

Галочка **HTTP** находится сразу справа от **Авто**. По умолчанию она снята, выбор сохраняется в файле настроек.

- **Авто включено, HTTP выключен:** основной канал ISS+ DEMO WebSocket (акции TQBR) и сохранённый SQLite-архив. Не выполняются HTTP-запросы свечей, MINSTEP и автоматического обновления списка инструментов. HTTP не включается при ошибке потока или необходимости сверки истории.
- **HTTP включен:** разрешены первая загрузка архива, недостающие таймфреймы, сверка после разрыва, периодический резервный HTTP; при стабильном WebSocket основным остаётся поток.
- **Новый компьютер без кэша:** короткие снапшоты WebSocket не содержат достаточной истории для индикатора v2.11. Для первого построения графика требуется временно отметить HTTP и загрузить историю, после чего можно снова запретить HTTP.
- **RFUD:** поток пока не реализован, поэтому без HTTP только ранее сохранённые свечи.
- Галочка запрещает **новые** HTTP-запросы; запрос, запущенный пока разрешение было включено, может завершиться.
