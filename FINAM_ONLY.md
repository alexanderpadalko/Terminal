# FlowDesk 0.2.26 — Finam Trade API only

Новый пользовательский EXE использует только Finam Trade API. MOEX ISS+ DEMO и TRANSAQ Connector не используются в приложении. В репозитории остаются архивные модули и тесты прежнего поставщика для проверок регрессий индикатора — они не запускаются новым приложением.

## Подключение

1. Создайте токен доступа типа «Просмотр» на https://api.finam.ru.
2. Запустите FlowDesk, нажмите **Токен Finam**, вставьте секрет в окно с маскировкой ввода. Он сохраняется в **Windows Credential Manager** через keyring, не в GitHub, SettingsStore или логах.
3. Введите тикер и MIC площадки (например, SBER + MISX, AAPL + XNAS, IBM + XNYS). Список предложений не подтверждает наличие прав на конкретный инструмент.
4. **Авто**: получать котировки/свечи по `wss://api.finam.ru/ws` (без регистрации торговых операций).
5. **HTTP**: отдельное явное разрешение на REST GET исторических свечей/восстановление. При снятой галочке работа с рынком идёт только через WebSocket и локально накопленную историю SQLite; сервисные POST /v1/sessions и /v1/sessions/details для авторизации разрешены всегда.
6. На новом компьютере для расчётов v2.11 сначала включите HTTP для заполнения базы, затем можете выключить.

Таймфреймы: M1, M5, H1, H4, D, W, M. Для каждого берутся исходные свечи Finam; вычисление структур и FVG выполняется прежним движком v2.11. Старые свечи сохраняются в отдельный файл `~/.flowdesk/finam_candles_v1.sqlite3`; данные MOEX никогда не смешиваются с ними.

**Безопасность:** в коде нет функций подачи торговых заявок, токен никогда не нужно вводить в чат. Доступность NYSE/NASDAQ и фактическую задержку определяют права токена. Пока нет живого теста с локальным токеном, корректность ответов WebSocket для всех семи ТФ и паритет с TradingView для американских часов торгов **не подтверждены**.

Finam ограничивает REST-глубину: M1 — 7 дней, M5/H1/H4 — 30 дней, D — 365 дней, W/M — примерно пять лет. Для истории сверх этих сроков необходимо долговременное сохранение данных со временем.
