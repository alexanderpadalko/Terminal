## Подключение

1. Создайте токен доступа типа «Просмотр» на https://api.finam.ru.
2. В FlowDesk откройте ⚙ → «Приложение» и введите токен. Он сохраняется в Windows Credential Manager, никогда в Git, логах или файле настроек.
3. При запуске автоматически проверяется каталог Finam, экспирации выбранных контрактов и топ-10 акций. Список строго 8 фьючерсов США + 10 акций РФ + 10 фьючерсов РФ + 2 Binance perpetual.
4. История читается из собственного SQLite-кэша; недостающие данные загружаются через HTTP. Следующие обновления догружают последние три свечи, не удаляя старый архив. Полная контрольная сверка обычного окна выполняется раз в сутки.
5. Открытый график обновляется через WebSocket. При разрыве/пропуске HTTP восстанавливает данные; при подтверждённо свежих свечах поток сверяется реже, по каждому TF отдельно. HTTP и WebSocket включены автоматически.
6. Скринер использует тот же кэш и общую очередь Finam-запросов, три параллельных исполнителя, приоритет графика и повторное использование расчётов. Архивная подкачка идёт после первичных результатов; обычный интервал прохода — пять минут.
7. Экспирация: только GetAsset/каталог Finam. Для Si/Eu сохраняется исходный регистр запроса и при необходимости добавляется локальный account_id. Нет Finam-даты — нет автоматического ролловера. MOEX остаётся исключительно для рейтинга акций.

Таймфреймы: M1, M5, H1, H4, D, W, M. Для каждого берутся исходные свечи Finam; вычисление структур и FVG выполняется прежним движком v2.11. Старые свечи сохраняются в отдельный файл `~/.flowdesk/finam_candles_v1.sqlite3`; данные MOEX никогда не смешиваются с ними.

**Безопасность:** в коде нет функций подачи торговых заявок, токен никогда не нужно вводить в чат. Доступность NYSE/NASDAQ определяется правами токена и наличием символа в справочнике Finam. Объявленная задержка в правах не является измерением фактического лага. Границы выполненной живой проверки приведены ниже; полный паритет TradingView **не подтверждён**.

С локально сохранённым ключом реально получены 176 H1 TSLA@XNGS через REST, котировка-снимок и семь WebSocket-снимков M1/M5/H1/H4/D1/W1/MN1. Потоковая проба выполнялась без рыночного HTTP. Права токена сообщают XNGS, delay_minutes=0; это не измерение фактического лага. Последняя котировка имела timestamp 12.11.2026 21:00:00 UTC и признак снимка; новые сделки/свечи во время торгов не наблюдались в этой короткой проверке.

Живой шлюз прислал JSON-текст внутри `payload` и Decimal-объекты `{value: ...}`. Декодер принимает их наряду с объектным payload и строковыми Decimal из документации. Перед запуском Finam worker вызывается `prepare_asyncio_runtime()` для frozen Python 3.15. Полный паритет TradingView, торговые сессии США и стабильность потока на длительном интервале ещё требуют проверки.

Диагностика: `python tools/check_finam_connection.py --symbol TSLA@XNGS --all-frames`. Рыночный REST включается только аргументом `--http`; дополнительный справочник — `--http --catalog`. Скрипт читает локальный ключ и выводит только безопасные результаты, без секретов и счетов.

Документация Finam указывает для REST: M1 — 7 дней, M5/H1/H4 — 30 дней, D — 365 дней, W/M — 365×5 дней. **Нельзя автоматически считать эти значения общим пределом доступной месячной истории.** Живая проверка 14.11.2026 старыми пятилетними интервалами реально получила SBER с июня 1999 года (330 месячных свечей) и LKOH с мая 1997 года (355). Один запрос сразу с 1990 года отклонялся HTTP 400. Все 38 инструментов и точные границы проверки: `docs/finam_monthly_history_2026-11-14.md`. Другие TF в этой проверке не исследовались; долговременное локальное сохранение остаётся необходимым.

## Часы биржи и Session VWAP (13.11.2026)

Временная шкала, время под курсором, заголовок OHLC и метки Finam отображают **биржевое время по MIC**, автоматически учитывая переходы DST: для `XNGS`, `XNYS`, `ARCX` используется `America/New_York`, для `MISX` — `Europe/Moscow`. Источник свечи продолжает храниться в UTC. Неизвестный MIC требует проверки, без угадывания зоны.

Для **акций США** `Session` VWAP включает все доступные M1/M5 свечи дневной расширенной сессии **04:00–20:00 ET**: премаркет, основную сессию, постмаркет. Единый накопительный объём/стоимость не сбрасывается в 09:30, 16:00 (полночь МСК зимой) или 00:00 ET. Новый VWAP начинается с первого доступного бара следующей сессии (обычно с 04:00 ET). Отдельная ночная сессия 21:00–04:00 ET в этот алгоритм не включена. Отсутствующие в Finam свечи не восстанавливаются искусственно. Неделя/месяц и другие календарные якоря VWAP группируются по дате биржи.

Профиль 04:00–20:00 ET основан на официальном расписании Nasdaq (https://www.nasdaq.com/market-activity). Неполные дни/праздничные исключения и другие площадки требуют отдельной сверки с биржевыми данными. См. `docs/exchange_time_vwap.md`.
