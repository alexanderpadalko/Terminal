# FlowDesk 0.2.26 — аналитический терминал Finam Trade API

**Актуальная пользовательская версия: 0.2.26 (Windows x64).** Только **Finam Trade API** в роли поставщика котировок; приложение не отправляет торговые заявки.

## Цифровая подпись EXE

Подготовлена подпись Windows через Microsoft Artifact Signing (OIDC). Пока сертификат издателя не подключён, GitHub публикует только `-UNSIGNED` сборки, которые могут вызывать SmartScreen. Настройка и проверка — [docs/CODE_SIGNING.md](docs/CODE_SIGNING.md); даже подлинная подпись не гарантирует мгновенную репутацию SmartScreen.

## Для пользователя

1. Откройте [GitHub Actions — Windows EXE](https://github.com/alexanderpadalko/Terminal/actions/workflows/build-windows.yml) и выберите последний **успешный** запуск на ветке `main`.
2. Скачайте artifact **FlowDesk-0.2.26-Finam-Windows-x64-UNSIGNED** (пока сертификат не настроен) или **...-SIGNED** после подтверждённой подписи, полностью распакуйте ZIP **в новую папку** и запустите `FlowDesk.exe`. Файл EXE нельзя переносить отдельно от остальных файлов комплекта.
3. Получите read-only токен на https://api.finam.ru (тип доступа **«Просмотр»**). В FlowDesk нажмите **«Токен Finam»** и вставьте секретный ключ. **Никому не отправляйте его** — приложение хранит секрет локально через Windows Credential Manager.
4. Выберите тикер/MIC из справочника Finam (например, `AAPL@XNGS`, `TSLA@XNGS`, `IBM@XNYS`, `SBER@MISX`). Для четырёх встроенных NASDAQ-примеров используется XNGS; прежний сохранённый выбор XNAS исправляется при запуске. Наличие инструмента в примерах не гарантирует права доступа.
5. **Авто** управляет Finam WebSocket. Галочка **HTTP** разрешает запросы REST для истории и восстановления; без неё рыночная HTTP-загрузка запрещена. HTTPS-авторизация выполняется независимо.

**Важные ограничения:** автоматические тесты и успешная сборка EXE не подтверждают доступность реального американского потока, задержку 0 минут, правильность биржевой сессии США или полный паритет TradingView. Это проверяется с локальным токеном пользователя.

13.11.2026 с локальным ключом проверены 176 H1 TSLA@XNGS и снимки котировки/свечей всех семи ТФ через WebSocket без рыночного HTTP. Это проверка снимков, а не доставки новых свечей во время торгов. Исправлены `lazy import` в frozen Finam worker, JSON-текст `payload` и Decimal-объекты живого шлюза. Подробности и ограничения — в [CURRENT_STATE.md](docs/CURRENT_STATE.md).

## Выбранные инструменты

Активный FlowDesk показывает фиксированные 4 фьючерса США, 13 фьючерсов РФ (включая мини/микро) и последние сохранённые ТОП-10 акций РФ. Скринера нет. **Автоматическая пересортировка акций, контроль экспираций и замена серии фьючерса отключены.** Показанный код контракта может истечь; данные сохраняются отдельно, новые серии автоматически не подставляются.

Доступны графики M5, H1, H4, D, W, M. **H1 — только свечи из Finam без индикаторов** в обычном окне графика; H4 по-прежнему строится только из H1, D/W/M используются как готовые свечи Finam.

Правая панель показывает **только список инструментов без встроенного скринера**, фильтров FVG и цветных LONG/SHORT-меток. Состав: 4 фьючерса США, 13 фьючерсов РФ (включая пять уменьшенных контрактов) и динамический ТОП-10 российских акций по обороту. Щелчок открывает выбранный график. Ежедневное обновление рейтинга, подтверждение фьючерсов по Finam и автоматический ролловер остаются; массовая фоновая проверка FVG по всем инструментам не выполняется.

В активном терминале **27 инструментов**: 4 фьючерса США, 13 фьючерсов РФ и динамический ТОП-10 акций РФ. Пять фьючерсов РФ теперь уменьшенные: MXI (`MMZ2026`, индекс мини), GOLDM (`GNZ2026`, золото мини), SILVM (`S1Z2026`, серебро мини), BRM (`BMZ2026`, Brent мини), NGM (`NRX2026`, природный газ **микро**). Остальные инструменты без изменений. Каждая позиция подтверждается точным тикером и MIC `RTSX` в Finam; обычный контракт не подставляется при отсутствии мини. Старые архивы цен не удаляются.

Рейтинг акций — официальный MOEX ISS VALUE/TQBR за 20 завершённых торговых сессий, с сохранением источника и даты. Подробное актуальное состояние в [docs/CURRENT_STATE.md](docs/CURRENT_STATE.md).

## Аналитика

- Эталон расчётов: **TradingView v2.11 H1 + H4**, 74 настройки.
- Таймфреймы: **M1 / M5 / H1 / H4 / D / W / M**.
- Структурная ломаная, потоки №1–3, FVG, старшая ликвидность/IDM, BOS/CHOCH/MAX/MIN, VWAP и сводка H1/H4/D/W/M.
- Для M1/M5 поток берётся из подтверждённого H1. Источник времени свечи — **биржевое время её начала**, не время доставки.
- Рыночная история: `~/.flowdesk/finam_candles_v1.sqlite3` (отдельно от старых данных MOEX).

## Разработчикам — один код для ChatGPT и локального Codex

**Единственная основная ветка — `main`.** Старые ветки сохранены под архивными Git-тегами; не работать из их копий. Перед каждой задачей и после неё читать:

- [AGENTS.md](AGENTS.md) — обязательные правила для Codex и ChatGPT.
- [docs/CURRENT_STATE.md](docs/CURRENT_STATE.md) — текущая карточка передачи и открытые вопросы.
- [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md) — решения двух чатов и архитектура.
- [docs/CHANGELOG.md](docs/CHANGELOG.md) — этапы.
- [FINAM_ONLY.md](FINAM_ONLY.md) — текущий API-поставщик.
- [docs/BRANCH_CLEANUP.md](docs/BRANCH_CLEANUP.md) — безопасное архивирование старых веток.

Работает **только один исполнитель за раз**. Следующий исполнитель получает `origin/main` после commit/push предыдущего. Секреты никогда не помещаются в репозиторий; `git reset --hard` и force-push запрещены без отдельного решения.

## Проверка и выпуск

Полная проверка в Windows Actions: тесты расчётов/Finam/Qt, упаковка PyInstaller, проверка закрытия EXE и executor/DNS через Finam worker готового EXE без токена. После исправлений добавлены регрессии реального payload, смены тикера/ТФ и миграции XNAS; локальный прогон — 355 тестов (1 пропущен). Актуальный зелёный CI является источником сборки. Вёрстка графика повторно использует `flowdesk/gui.py` (CandleChart), а новый запуск `main.py` использует `flowdesk/finam_gui.py`.

Репозиторий хранит историю старого MOEX-движка только для регрессионной совместимости и архива. Старые страницы README, старые артефакты и прежние источники данных **не являются актуальными версиями**.
